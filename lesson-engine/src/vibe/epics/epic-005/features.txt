
# Epic-005 - Let's Find: Boxes Mode

## Overview

Implement the Let's Find activity, beginning with its Boxes mode.

Let's Find will eventually contain two modes:
- Houses
- Boxes

Only Boxes mode will be implemented in this epic.

The purpose of Boxes mode is to help children associate English words with objects through an interactive hiding and finding game.

The player is shown an object to find. Several coloured boxes appear, an object moves beneath one of them, and the boxes lower to hide it.

The player must then select the correct box.

The activity must support:
- 2, 3 or 4 boxes.
- Six possible box colours.
- Three object categories.
- Random object selection.
- Random box colour selection.
- Random box order.
- Random object hiding locations.
- Fresh random selections for every new game.
- Animated introduction and preparation.
- Animated object movement and hiding.
- Interactive box selection.
- Incorrect-answer feedback.
- Correct-answer celebration.
- Playing again with the same settings but new random selections.
- Navigation to the Boxes options screen or homepage.

The game will use a white and light blue animated background with dark blue text.

All animation stages must preserve stable layout positions.

The global Options menu must remain accessible throughout the activity.

Follow all existing application conventions established in Epics 001-004.
